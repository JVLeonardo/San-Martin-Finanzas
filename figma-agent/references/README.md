## Deliberately excluded

- **Logo derivatives and masters:** duplicate sizes, vertical/master sources, monochrome alternatives, and masters are excluded because the four chosen variants cover light/dark desktop/mobile use directly.
- **Icons:** app icon and favicon are metadata assets, not normal-screen UI assets; no PWA/app metadata screen is in scope.
- **Symbols:** all alternate dimensions are excluded; the selected isotype and reduced symbol have the only planned UI uses.
- **Regional graphics:** WebP duplicates, unused sizes, fragments, microaccent, route vertical, and alternate crops are excluded. A dark horizon is unavailable and must not be invented.
- **Guideline plates:** plates 1, 3, and 9 repeat or are less directly actionable than the six retained plates.
- **Photography:** no final approved/licensed photography exists. The retained photography plate is direction only.
- **Technical material:** masters, manifests, reports, candidates, previews, scripts, and temporary files are excluded.

## Integrity rules

Use assets as provided. Do not trace, recolor, crop, stretch, flatten, or recreate them. Refer to `../brand-usage.md` for placement and density rules. If a needed asset is absent, retain the issue as pending instead of improvising a substitute.
