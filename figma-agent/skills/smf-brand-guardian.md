# San Martín Finanzas — Brand Guardian

Apply these rules to every selected design or new UI you create.

## Brand identity

Use only the approved San Martín Finanzas visual identity.

Colors:
- Forest 900 — #0E3F2B
- Forest 700 — #145C3A
- Forest 500 — #2F7D57
- Earth Gold — #C79A52
- Warm White — #F7F4EE
- White — #FFFFFF
- Ink — #24312B
- Muted — #66736D
- Border — #DCE5DF

Principle:
GREEN IDENTIFIES. GOLD ACCENTS.

Earth Gold must remain a restrained accent. Do not use it as the dominant background, standard primary CTA color, or long-form text color.

Typography:
- Cormorant Garamond SemiBold → editorial/display headings
- Source Sans 3 → UI, body text, forms, navigation and data

Do not introduce other typefaces unless explicitly instructed.

## Language

ALL visible user-facing content must be in Spanish (Peru).

This includes:
- headings
- navigation
- buttons
- CTAs
- form labels
- placeholders
- helper text
- errors
- validation messages
- simulator labels
- FAQ
- footer
- mobile UI
- states
- confirmations

English may only remain in internal Figma layer names or technical documentation when useful.

Never leave visible English UI text in the product.

## Approved brand assets

Use only approved assets already available in the file.

Do not:
- redraw logos
- recolor logos
- generate replacement logos
- distort assets
- invent symbols
- substitute brand graphics

Brand hierarchy:
- Full horizontal logo → primary identity
- Compact logo / Isotype → compact contexts
- Compact Monochrome Light/Dark → secondary controlled applications
- Eagle Symbol → digital brand mark
- App Icon / Favicon → digital platform identity

## Graphic system

La Ruta:
journey, direction, continuity and progress.

Horizonte:
territorial atmosphere and regional depth.

Topografía:
subtle secondary texture.

Use these intentionally.

Do not combine La Ruta + Horizonte + Topografía indiscriminately.

Avoid:
- generic SaaS aesthetics
- crypto aesthetics
- cold traditional banking visuals
- tourism clichés
- excessive cards
- excessive green
- excessive decoration
- AI-template appearance

San Martín Finanzas should feel:
regional, professional, warm, clear, contemporary, editorial and distinctive.
