# Brand assets

This directory is the reproducible raster asset source for the San Martín Finanzas MVP.

## Structure

- `masters/`: approved raster sources. Never edit, resize, crop, recolor, optimize, or overwrite these files during derivative generation.
- `logos/raster/`: generated logo sizes.
- `symbols/`: generated isotype and reduced-symbol sizes.
- `icons/app/`: generated App/PWA icon sizes.
- `icons/favicon/`: generated browser favicon PNGs and multi-resolution ICO.
- `graphics/route/`, `graphics/topography/`, `graphics/horizon/`: approved regional graphic masters plus reproducible `raster/` (PNG) and `web/` (lossless WebP) derivatives.
- `reports/`: audit evidence and machine-readable generated-file inventory.

| Family | Source master |

| Horizontal logo | `masters/smf-logo-horizontal.png` |
| Isotype | `masters/smf-isotype-master.png` |
| Reduced symbol | `masters/smf-symbol-master.png` |
| App/PWA icon | `masters/smf-app-icon-master.png` |
| Favicon | `masters/smf-favicon-master.png` |

Derivatives must never be edited manually. Regenerate them from the masters:

```powershell
.\scripts\brand\generate-brand-assets.ps1
```

Regional graphics are generated independently, so the primary identity pipeline remains isolated:

```powershell
.\scripts\brand\generate-brand-graphics.ps1
```

The generator preserves aspect ratio and alpha, uses high-quality bicubic resampling, refuses upscaling, verifies that master hashes remain unchanged, and records generated, omitted, and blocked outputs. Existing derivatives are not rewritten when the generated bytes are identical. Human-approved negative and monochrome variants use deterministic flat-color transformations with the original source alpha and canvas preserved. The favicon ICO embeds the approved 48, 32, and 16 px PNG derivatives without visual reinterpretation.

## Current status

- Raster masters are the visual source of truth for the MVP.
- Vector status is `pending`; no SVG is generated or implied.
- Seven approved raster masters are available, including dedicated square App/PWA and favicon masters.
- The pipeline generates 47 official assets: 46 PNG files and one multi-resolution ICO.
- The regional graphics pipeline generates 42 official derivatives: 21 PNG files and 21 lossless WebP files from three approved masters.
- Negative and monochrome variants are official for the current project following explicit human visual approval.
- No primary-identity asset family is blocked. Nine identity requests are intentionally omitted: five to prevent upscaling and four monochrome sizes below the approved 240 px tagline minimum.
- Graphic-system limitations are explicitly recorded: route extension, seamless topography extension, and a dark horizon require dedicated approved masters. The regional graphic derivatives are not identity assets and do not alter logo, icon, or symbol sources.
